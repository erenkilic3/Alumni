🐳 Container Topology (docker-compose.yml)

The system is isolated into distinct lightweight containers orchestrated via Docker Compose:

Database

db (PostgreSQL 16)

Persistent storage via Docker volume pgdata. Relational tables for users, profiles, career timelines.

Port: 5432:5432
Backend

server (Node.js & Express)

REST API with JSON validation, CORS guards, and PostgreSQL connection pool.

Port: 5000:5000
Frontend

client (Web UI + Dark Mode)

Interactive client interface with theme synchronization and real-time query engine.

Port: 3000:3000

⚡ Quick Terminal Commands

Start all containers:
docker compose up --build
Local Development without Docker:
npm run install:all
# In terminal 1:
npm run server
# In terminal 2:
npm run client
